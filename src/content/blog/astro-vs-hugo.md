## 背景

选博客框架的时候，主要看了 Hugo 和 Astro 两个。

## Hugo

- Go 写的，构建极快，几千篇文章秒出
- 主题生态丰富，但模板语法是 Go template，写起来不太舒服
- 想自定义样式的话，要翻别人的主题代码改，比较痛苦

## Astro

- 前端技术栈，组件用 Astro / React / Vue 都行，写起来舒服
- 默认零 JS 输出，页面就是纯 HTML + CSS，加载极快
- 内容集合（Content Collections）自带类型校验，写文章有补全
- 构建速度对博客量级来说完全够用

## 结论

博客不是大型站，几百篇文章的量级，Hugo 的速度优势体现不出来。但 Astro 的开发体验好很多，而且如果你以后想加交互（比如搜索、暗色切换），直接写个 React 组件塞进去就行，不用像 Hugo 那样折腾短代码。

> 选工具的标准不是哪个最强，而是哪个让你愿意持续用下去。
